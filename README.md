# Todo App

A simple Todo app built with HTML, CSS, and JavaScript.

This was my first web development project. I built it to practice JavaScript and create an interactive web page.

## Features

* Add tasks
* Mark tasks as complete
* Delete tasks
* Save tasks with `localStorage`
* Keep tasks after refreshing the page

## Tech Stack

* HTML
* CSS
* JavaScript

## What I Learned

* DOM manipulation
* Event handling
* `localStorage`
* Working with JavaScript objects and arrays

## Project Purpose

This project was my first step into web development and helped me build a foundation in JavaScript.
